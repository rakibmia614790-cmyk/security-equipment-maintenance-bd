# Manufacturer Logo Sources

Logos should be used only from official manufacturer-provided sources
or assets for which appropriate usage permission is available.

## Verified Official Sources

- Smiths Detection
  https://www.smithsdetection.com/download-centre/

- Rapiscan Systems
  https://www.rapiscansystems.com/
  Note: Review trademark/material-use terms before copying official logo assets.

- CEIA
  https://www.ceia.net/

- Nuctech
  https://www.nuctech.com/

## Usage Rule

Do not use unofficial, modified, distorted, or misleading manufacturer logos.
Do not imply authorization, dealership, partnership, or certification unless
such status is independently verified and explicitly documented.
